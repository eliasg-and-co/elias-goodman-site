# stems

Five loops, one per icon. Same length, same tempo, same start point.
They start on one clock and loop together.

    writing.mp3   -> delay     (time 0.375s, feedback 0.45)
    doux.mp3      -> reverb    (2.6s tail)
    eegee.mp3     -> lowpass   (18k down to 220Hz)
    built.mp3     -> drive
    contact.mp3   -> tremolo   (5.5Hz)

Drag an icon toward the drop zone and its effect comes up. Home is dry,
in the zone is fully wet. Left/right position pans the stem.

Any file missing here is skipped. If none are present, [ play ] uses
loop.mp3 as before. Mapping and options live in STEMS in index.html.
