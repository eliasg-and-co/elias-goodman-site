# sfx

Short one-shots -- chimes, white noise, foley, whatever. Fired when a
dragged icon knocks the hero text out of place: one per hit, random
pick, slight rate jitter, at most one every 90ms.

Name them 01.mp3, 02.mp3, 03.mp3, 04.mp3 or edit SFX_FILES in index.html.
Missing files are skipped. Until any load, a soft sine chime stands in.

Sound only plays once [ play ] has been pressed.
